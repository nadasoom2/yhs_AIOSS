## 개요

UniGuide AI (외국인 유학생 행정 도우미 앱)의 Feature Flag 기반 A/B 테스트를 **LLM 페르소나 시뮬레이션**으로 2주 운영했습니다.

- **시뮬레이션 기간:** 2026-05-01 ~ 2026-05-14 (14일)
- **페르소나:** 10명 (국적·한국어 수준·비자 유형 각기 다름)
- **LLM 모델:** GPT-4o-mini (각 페르소나가 실제 질문·피드백 생성)
- **실험 수:** 2개 (환영 메시지, 채팅 레이아웃)
- **Feature Flag 연결:** `CHAT_LAYOUT` 실험은 `QUICK_REPLIES` 플래그가 켜진 사용자에게만 진입

## A/B 실험 결과 요약

### 실험 1 — 환영 메시지 (WELCOME_MESSAGE)

| 지표 | A: "한국 유학 생활, 더 쉽게" | B: "AI 에이전트가 비자·행정 문제를 단번에" | 차이 |
|------|------|------|------|
| 평균 만족도 | 3.64 / 5 | 4.05 / 5 | **+0.41** |
| 리텐션율 | 66.0% | 67.0% | +1.0%p |
| 주당 평균 세션 | 4.6회 | 4.7회 | +0.1회 |
| 태스크 완료율 | 62.0% | 82.0% | **+20.0%p** |

→ **Variant B 우세** — AI 기능 강조 문구가 유학생의 관심을 더 효과적으로 포착. 특히 태스크 완료율이 20%p 높아 실질적 도움 체감도가 더 큼

### 실험 2 — 채팅 레이아웃 (CHAT_LAYOUT)

| 지표 | A: 입력창 단독 | B: 추천 질문 카드 + 입력창 | 차이 |
|------|------|------|------|
| 평균 만족도 | 3.77 / 5 | 3.92 / 5 | **+0.15** |
| 리텐션율 | 61.0% | 71.0% | **+10.0%p** |
| 주당 평균 세션 | 4.3회 | 5.0회 | +0.7회 |
| 태스크 완료율 | 80.0% | 64.0% | -16.0%p |
| 추천 카드 클릭 | 0회 | **45회** | — |

→ **리텐션·참여는 B 우세, 태스크 완료율은 A 우세** — 추천 카드가 진입 장벽은 낮추지만, 한국어 초급 페르소나(압둘라·카일)가 카드 클릭 후에도 절차를 끝까지 완수하지 못해 완료율이 낮아짐

## 통계적 한계

> ⚠️ 실험당 n=5 (variant A 5명, variant B 5명) — 현재 수치는 **방향성 참고용**이며 통계적 유의성 검정 불가. 실제 서비스 배포 후 최소 2주·n≥200으로 재측정 권장.

## 결정 기록 (Decision Log)

| 결정 | 내용 | 이유 |
|------|------|------|
| 시뮬레이션 방식 | 실제 2주 측정 대신 LLM 페르소나 시뮬레이션 | 과제 조건이 "LLM 페르소나 패턴" 명시 |
| A/B 배정 방식 | 명시적 2×2 factorial 배정 (각 5명) | 해시 기반 배정 시 10명 모두 동일 그룹 편향 발생 |
| 측정 지표 | 리텐션율·만족도·완료율·QR클릭 | Feature Flag 핵심 지표 (참여·만족·전환) |
| 태스크 완료율 | 한국어 초급·기술 능숙도 낮음 페르소나는 실패 허용 | 초기 버전은 100% 고정으로 지표 변별력 없었음 |
| Feature Flag 연결 | CHAT_LAYOUT 실험을 QUICK_REPLIES 플래그로 게이팅 | Flag OFF 시 실험 진입 차단, Flag↔실험 명시적 연결 |
| 채택 Variant | WM: B, Layout: 지표에 따라 혼재 | WM-B는 만족도·완료율 모두 우세; Layout-B는 리텐션↑ but 완료율↓ |
| 통계 한계 | n=5로 유의성 검정 불가 | 실제 서비스 배포 후 n≥200 재측정 권장 |
